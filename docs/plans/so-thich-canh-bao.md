### SQL ghi: kịch bản chạy thử trên Postgres local (Claude chat chạy trước khi chủ dự án chạy trên production)

CI chỉ dựng DB từ `schema.sql`, **file migration chưa từng chạy** → phải chạy thử đúng file sẽ cắt. Dữ liệu thử chỉ tạo trên DB local: admin A (`profiles.role = 'admin'`), user thường U và V, vài danh mục / tác giả / NXB / sách. Mỗi ca ghi: câu chạy, mã lỗi / số dòng nhận được, khớp / không khớp.

**Môi trường.** Ưu tiên Postgres của Supabase (Supabase CLI hoặc image `supabase/postgres`): có sẵn role, quyền mặc định trên schema `public`, `auth`, `storage`. Không có thì shim, chạy **trước** khi dựng `schema.sql`, đúng thứ tự:
1. `create role anon nologin; create role authenticated nologin; create role service_role nologin;`
2. Schema `auth` + `auth.users` (đủ cột mà trigger tạo `profiles` của `schema.sql` đọc) + `auth.uid()` đọc `request.jwt.claims`: `create function auth.uid() returns uuid language sql stable as $$ select (nullif(current_setting('request.jwt.claims', true), '')::jsonb ->> 'sub')::uuid $$;`. Schema `storage` (`buckets`, `objects`, `foldername`) và `extensions` đủ để `schema.sql` chạy qua.
3. `grant usage on schema public, auth, extensions to anon, authenticated, service_role;` (`auth` và `extensions` cũng cần: trigger `books_search_text` (`books_build_search_text` → `normalize_vi`) **không** security definer, chạy bằng quyền người sửa sách và gọi `extensions.unaccent`; policy RLS, default của `user_blocks.user_id` và các hàm gọi `auth.uid()` bằng quyền của `authenticated`. Thiếu thì admin sửa sách / user thêm giỏ lỗi `42501` vì môi trường, không phải vì migration.)
4. Quyền mặc định như Supabase, cho đúng role sẽ tạo đối tượng (role dựng `schema.sql` + chạy migration): `alter default privileges for role <role> in schema public grant all on tables to anon, authenticated, service_role;` + `… grant all on sequences to …` + `… grant execute on functions to …`.
5. Dựng `schema.sql` và chạy migration bằng **đúng role đó**; ghi vào kết quả role đó có phải superuser không (`select rolsuper from pg_roles where rolname = current_user`).

**Bước kiểm bắt buộc trước migration** (chứng minh quyền mặc định có thật; không thì mọi ca chờ `42501` là "đạt giả"): `select has_table_privilege('anon', 'public.books', 'insert')` = `true`, `has_schema_privilege('authenticated', 'auth', 'usage')` = `true`, `has_schema_privilege('authenticated', 'extensions', 'usage')` = `true`. **Đối chứng dương** (thao tác hợp lệ phải qua, chứng minh khung giả lập đủ quyền; admin A, user U và sách S (superuser) tạo trước bước này; mỗi câu một transaction rồi `rollback;`): (1) admin A (`set local role authenticated` + claims của A) `update public.books set title = title where id = <S>` → 1 dòng, không lỗi; (2) user U (`set local role authenticated` + claims của U) `insert into public.cart_items (user_id, book_id, quantity) values ('<U>', <S>, 1)` → qua. Đỏ ở đây thì sửa shim trước, **không** chạy tiếp. **Sau migration**: `has_table_privilege('anon', 'public.user_blocks', 'select')` = `false`, `has_table_privilege('authenticated', 'public.content_warning_suggestions', 'update')` = `false`.

**Transaction.** Đổi vai trò: `begin; set local role authenticated; set local request.jwt.claims = '{"sub":"<uuid>","role":"authenticated"}'; …` (anon: `set local role anon`, claims `{"role":"anon"}`). Ca cần cộng dồn (ca 1) kết thúc bằng `commit;`. Mỗi ca chờ lỗi chạy trong transaction riêng rồi `rollback;` (hoặc `savepoint` / `rollback to savepoint`), sau đó đọc lại bằng superuser **ngoài** transaction đó. `now()` là giờ bắt đầu transaction: so thời điểm thì giá trị cũ phải đến từ transaction đã commit trước đó.

- Thẻ sách (`BookCard`, thẻ chợ sách cũ, dòng palette) mang `data-*` (id danh mục, id tác giả vai trò `author`, id NXB, nhãn) + ô mờ cùng kích thước ("Đã ẩn theo sở thích của bạn" + nút "Xem"). Trang prerender giữ nguyên cho mọi người (không bỏ cache catalog).
- Che bằng `<style>` từ server trong Suspense của layout, sau khi đọc phiên (một query `user_blocks` của chính user; danh mục cha mở ra mọi danh mục con). **Câu 3a**: phần nội dung (link sách) `visibility: hidden` → không nhận Tab, trình đọc màn hình bỏ qua; chỉ ô mờ + nút "Xem" đọc / bấm được; e2e kiểm link sách bị chặn không nhận focus. Ô mờ **không** dùng thuộc tính `hidden` (Tailwind v4 có `[hidden] { display: none !important }`), hiện / ẩn bằng chính style sinh ra. **Câu 3b**: CSS chỉ dựng từ id số nguyên + tên nhãn enum đã kiểm, không chứa chữ người dùng nhập; Vitest (input bẩn bị loại).
- "Xem": một client leaf nhỏ ở layout bắt click ủy quyền, gắn `data-revealed` cho đúng thẻ (lần xem này). Đo thời gian lộ trên Preview (câu 3).
- Trang sách: nút "Không muốn thấy thể loại / tác giả (vai trò author) / NXB này" + "Ẩn các sách có cảnh báo này" (mọi nhãn của cuốn đó); sách bị chặn → dòng nhắc "Bạn đã chặn …" + bỏ chặn; khách chưa đăng nhập không thấy nút. Chừa chỗ để không CLS.
- Trang Sở thích (`/tai-khoan/so-thich` ↔ `/en/account/preferences`): liệt kê theo nhóm, bỏ chặn.
- Mây lọc ứng viên + thẻ trả về theo mục chặn của người hỏi (câu 10). Palette làm cuối (câu 11).
- e2e: user e2e riêng mỗi lần chạy (xóa ở `finally`), sách e2e riêng; ô mờ cùng kích thước, Xem, tải lại che lại, dòng nhắc, bỏ chặn, khách không thấy nút, người khác không đọc được danh sách chặn.
- Ghi chú từ review P-A (vòng 2): thống nhất thuật ngữ chặn / ẩn ở mọi chỗ: nút "Không muốn thấy …" (hành động), ô mờ "Đã ẩn theo sở thích của bạn" (kết quả), trang "Sở thích" và dòng nhắc "Bạn đã chặn …" dùng cùng một bộ từ trong cả vi / en; rà lại messages trước khi lên main.

## Các chỗ đã sửa so với bản kế hoạch đầu (điều phối vòng 0 + chủ dự án)

- Tên migration 14 chữ số (`20261025000000_…`).
- Chống trùng `user_blocks` bằng unique theo từng kind (partial index), không unique trên cả bộ cột.
- Chuẩn hóa nhãn bằng trigger thay CHECK gọi hàm `private`.
- Ô mờ không dùng thuộc tính `hidden` (Tailwind v4 `[hidden]{display:none !important}`).
- User e2e riêng mỗi lần chạy cho spec chặn.
- `safetySettings` + timeout / `maxOutputTokens` riêng cho lô gợi ý.
- Trần cứng `warn:day` trong SQL (60); thêm đếm chung `gemini:minute` + `gemini:day` với ngưỡng 300 (câu 5 sửa) thay vì "không đụng 400 của Mây".
- CLS ở trang sách (khung cảnh báo, nút chặn, dòng nhắc chừa chỗ).
- Test lô chỉ kiểm ≤ 12 cuốn / lượt.
- Palette bỏ dòng bị che khỏi điều hướng phím.
- Duyệt nhãn làm mới cả `chat-catalog`.
- `ticket.ts` / `callGemini` mở rộng ở P-B (không ở P-A).
